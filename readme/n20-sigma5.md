Отлично! Теперь делаем **строго по алгоритму**, без упрощений. Сжатие запускается **немедленно**, как только `len(C) > δ/2`. При δ=5: `δ/2 = 2.5`, значит сжатие при `len(C) ≥ 3`.

Я буду **очень подробно** комментировать каждый шаг: почему создаём, почему сливаем, почему сжатие даёт именно такой результат.

# 📐 Подготовка

**Scale function:** `k(q) = (2.5/π) · arcsin(2q − 1)`

**Таблица k(q)** (ключевые значения):

| q | k(q) | q | k(q) |
|---|------|---|------|
| 0.000 | −1.250 | 0.500 | 0.000 |
| 0.050 | −0.891 | 0.550 | 0.080 |
| 0.100 | −0.738 | 0.600 | 0.160 |
| 0.150 | −0.617 | 0.650 | 0.242 |
| 0.200 | −0.512 | 0.700 | 0.327 |
| 0.250 | −0.417 | 0.750 | 0.417 |
| 0.300 | −0.327 | 0.800 | 0.512 |
| 0.350 | −0.242 | 0.850 | 0.617 |
| 0.400 | −0.160 | 0.900 | 0.738 |
| 0.450 | −0.080 | 0.950 | 0.891 |
| 0.500 | 0.000 | 1.000 | 1.250 |

**Правило:** кластер допустим, если `k(q_right) − k(q_left) ≤ 1`.

**Правило сжатия:** после каждого добавления, **пока** `len(C) > 2.5`, выполняем один проход merge. Если проход не уменьшил число центроидов — останавливаемся.

## 🎯 P90 (q = 0.90)

**Позиция:** q_2 = 0.875 < 0.90 → **правый хвост**.

**Последний кластер** (11.00, 5) = {9, 10, 15, 10, 11}. Максимум = 15.

Интерполируем между q_2 = 0.875 (c=11) и q=1.0 (c=15):

```
P90 = 11 + (15 − 11) · (0.90 − 0.875) / (1.0 − 0.875)
    = 11 + 4 · (0.025 / 0.125)
    = 11 + 4 · 0.2
    = 11 + 0.8
    = 11.80
```

**✅ P90 = 11.80**

# 🎓 ГЛАВНЫЕ ВЫВОДЫ

1. **Сжатие запускается после каждого шага**, если `len(C) > δ/2`. При δ=5 — как только центроидов ≥ 3.

2. **Сжатие — это итеративный процесс.** Один проход может не дать результата, тогда останавливаемся. Если дал — пробуем ещё раз.

3. **Порядок слияний влияет на результат.** В корректном алгоритме кластеры формируются иначе, чем в упрощённом.

4. **Финальный digest** = `[(1.25, 4), (5.36, 11), (11, 5)]`, n=20.

5. **P90 = 11.80, P95 = 13.40.** Ошибки большие (1.80 и 3.35), потому что n=20 мало для δ=5.

6. **Выброс 15** снова «загрязнил» последний кластер, потому что при n=20 он составляет 5% данных и не может быть изолирован.
