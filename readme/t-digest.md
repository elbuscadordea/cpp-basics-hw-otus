## 🧮 Числовой пример с формулами

Возьмём **scale function k₁** (классическая, используется в большинстве реализаций):

```
k₁(q) = (δ / 2π) · arcsin(2q − 1)
```

Пусть **δ = 100** (параметр сжатия). Тогда:

```
k₁(q) = (100 / 2π) · arcsin(2q − 1) = (50/π) · arcsin(2q − 1)
```

Диапазон: `k₁(0) = −25`, `k₁(1) = +25`. Полная длина `k`-пространства = 50.

---

### 📊 Шаг 1: Считаем границы кластеров

Правило: `k(q_right) − k(q_left) ≤ 1`. Значит, всё `k`-пространство длиной 50 делится максимум на **50 кластеров** (на практике ~50–60).

Посчитаем, где проходят границы для нескольких квантилей:

| q | 2q−1 | arcsin(2q−1) | k₁(q) = (50/π)·arcsin | Δk от предыдущего |
|---|------|--------------|----------------------|-------------------|
| 0.000 | −1.000 | −π/2 ≈ −1.571 | **−25.00** | — |
| 0.001 | −0.998 | −1.526 | **−24.29** | 0.71 |
| 0.010 | −0.980 | −1.369 | **−21.79** | 2.50 |
| 0.100 | −0.800 | −0.927 | **−14.75** | 7.04 |
| 0.300 | −0.400 | −0.412 | **−6.55** | 8.20 |
| 0.500 | 0.000 | 0.000 | **0.00** | 6.55 |
| 0.700 | 0.400 | 0.412 | **6.55** | 6.55 |
| 0.900 | 0.800 | 0.927 | **14.75** | 8.20 |
| 0.990 | 0.980 | 1.369 | **21.79** | 7.04 |
| 0.999 | 0.998 | 1.526 | **24.29** | 2.50 |
| 1.000 | 1.000 | π/2 ≈ 1.571 | **25.00** | 0.71 |

**Что это значит:** `Δk` между q=0.000 и q=0.001 равно всего 0.71 — значит, там может быть несколько кластеров. А `Δk` между q=0.100 и q=0.300 равно 8.20 — значит, там поместится ~8 кластеров на широком диапазоне q. Парадокс? Нет: **кластеры на хвостах крошечные по количеству точек, но их много по количеству; в центре кластеры крупные, но их мало.**

### 📊 Шаг 2: Конкретный пример с n = 10 000 точками

Пусть у нас 10 000 точек, равномерно распределённых от 0 до 1000 мс.

**Сколько точек в кластере, начинающемся с квантиля q_left?**

Число точек в кластере = `n · (q_right − q_left)`, где `q_right` находится из условия `k(q_right) = k(q_left) + 1`.

**Пример A: кластер на левом хвосте (q ≈ 0.001)**

```
k(q_left) = k(0.001) = −24.29
k(q_right) = −24.29 + 1 = −23.29
```

Обратная функция: `q = (1 + sin(π·k/50)) / 2`

```
q_right = (1 + sin(π·(−23.29)/50)) / 2 = (1 + sin(−1.463)) / 2
        = (1 + (−0.994)) / 2 = 0.003
```

Точек в кластере: `10 000 · (0.003 − 0.001) = 10 000 · 0.002 = 20 точек`

Хм, 20 — не так мало. Давайте возьмём ещё более крайний случай.

**Пример B: самый левый кластер (q ≈ 0)**

```
k(q_left) = k(0) = −25
k(q_right) = −25 + 1 = −24
q_right = (1 + sin(π·(−24)/50)) / 2 = (1 + sin(−1.508)) / 2
        = (1 + (−0.998)) / 2 = 0.001
```

Точек: `10 000 · 0.001 = 10 точек`

**Пример C: кластер в центре (q ≈ 0.5)**

```
k(q_left) = k(0.5) = 0
k(q_right) = 0 + 1 = 1
q_right = (1 + sin(π·1/50)) / 2 = (1 + sin(0.0628)) / 2
        = (1 + 0.0628) / 2 = 0.5314
```

Точек: `10 000 · (0.5314 − 0.5) = 10 000 · 0.0314 = 314 точек`

**Вот она, адаптивность!**

| Положение | Точек в кластере |
|-----------|------------------|
| Левый хвост (q≈0) | **10** |
| Левый хвост (q≈0.001) | **20** |
| Центр (q≈0.5) | **314** |

---

### 📊 Шаг 3: Как это влияет на точность перцентиля

Допустим, нам нужен **1-й перцентиль (q = 0.01)**.

Смотрим в таблицу: `k(0.01) = −21.79`. Ближайший кластер — тот, что покрывает q от 0.01 до ~0.012 (следующий шаг k).

Ширина кластера в q: `Δq ≈ 0.002`. В точках: `10 000 · 0.002 = 20 точек`.

**Ошибка оценки:** мы знаем только среднее кластера, а не точное значение каждой из 20 точек. Максимальная ошибка по q — это половина ширины кластера, т.е. `0.001` или **0.1%**. В абсолютных значениях (диапазон 0–1000 мс): `0.001 · 1000 = 1 мс`.

Теперь **50-й перцентиль (q = 0.5)**. Кластер шириной `Δq ≈ 0.0314`. Ошибка по q — половина, т.е. `0.0157` или **1.57%**. В абсолютных значениях: `15.7 мс`.

**Вывод:** на хвосте ошибка в **15 раз меньше**, чем в центре. Именно этого мы и добивались!

### 📊 Шаг 4: Формула в общем виде

Для scale function k₁:

```
Число точек в кластере ≈ n · dq,  где  dq = dk / k'(q)
```

Производная: `k₁'(q) = (δ/2π) · (2 / √(1−(2q−1)²)) = (δ/π) · 1/√(4q(1−q))`

При `dk = 1`:

```
Размер кластера ≈ n · π · √(4q(1−q)) / δ = (2π·n/δ) · √(q(1−q))
```

**Проверка:**

- При q = 0.5: `√(0.25) = 0.5` → размер ≈ `(2π·10000/100)·0.5 = 628·0.5 = 314` ✅ (совпало с примером C!)
- При q = 0.001: `√(0.001·0.999) ≈ 0.0316` → размер ≈ `628 · 0.0316 = 19.8 ≈ 20` ✅ (совпало с примером A!)

**Вот она — та самая формула из моего первого объяснения:** размер кластера пропорционален `√(q(1−q))`. На краях это почти ноль → кластеры крошечные. В центре максимум → кластеры крупные.
